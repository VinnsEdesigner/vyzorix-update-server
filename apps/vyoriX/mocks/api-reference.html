GET /v1/devices
Retrieve a list of devices with optional filtering by status, tags, or last seen time.
Parameter Type Required Description
status string optional Filter by status: online, offline, pending
limit integer optional Number of results (1-100, default: 20)
cursor string optional Pagination cursor from previous response
Request 
curl -X GET "https://api.vyzorix.io/v1/devices?status=online&limit=10"   -H "Authorization: Bearer vk_live_xxxxxxxxxxxx"   -H "Content-Type: application/json"

POST /v1/devices/{imei}/commands
Send a command to a specific device. All commands are HMAC-SHA256 signed for security.
Parameter Type Required Description
imei string required Device IMEI (15 digits)
command string required Command name (e.g., FORCE_SPEAKER, RESET_AUDIO_HAL)
params object optional Command-specific parameters
Request 
curl -X POST "https://api.vyzorix.io/v1/devices/861234567890123/commands"   -H "Authorization: Bearer vk_live_xxxxxxxxxxxx"   -H "Content-Type: application/json"   -d '{
    "command": "FORCE_SPEAKER",
    "params": {}
  }'
Response 
{
  "id": "cmd_a1b2c3d4e5f6",
