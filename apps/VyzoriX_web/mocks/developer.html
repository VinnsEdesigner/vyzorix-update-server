Installation npm
API Key Required
Get your API key from Settings â API Keys. All requests must include Authorization: Bearer YOUR_API_KEY
Install the SDK 
npm install @vyzorix/sdk
Initialize client 
import { VyzorixClient } from '@vyzorix/sdk';

const client = new VyzorixClient({
  apiKey: 'vk_live_xxxxxxxxxxxx',
  region: 'us-east-1'
});
Get device info 
// Fetch device details
const device = await client.devices.get(
  '861234567890123'
);

console.log(device.name);      // "Pixel 8 Pro"
console.log(device.status);   // "online"
Send command 
const result = await client.commands.send({
  imei: '861234567890123',
  command: 'FORCE_SPEAKER'
});

console.log(result.id);        // "cmd_abc123"
console.log(result.status);   // "pending"
