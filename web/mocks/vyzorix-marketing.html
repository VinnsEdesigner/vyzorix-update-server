§ 01

What it does

Lifecycle

Register, approve, retire

Devices register via an HMAC-signed endpoint and move through a state machine: pending → registered → deregistered. Soft-deletes hold data for 30 days before permanent removal.

Updates

OTA from GitHub releases

Webhook sync with GitHub releases creates versioned APK entries automatically. Push updates to individual devices, groups, or the whole org. Track per-device install status.

Commands

Remote execution, signed

Every command is HMAC-signed with the device's secret. Risk-tiered authorization gates destructive commands behind MFA and single-use confirmation tokens.

Telemetry

Real-time over WebSocket

Battery, CPU, memory, temperature, and network metrics stream live. Threshold crossings generate device events automatically. The dashboard sees everything as it happens.

Access Control

Scoped RBAC + device groups

Organizations, teams, and per-resource permissions. An operator commands their devices; a team member commands group devices; an admin commands anything in the org.

Audit

Every action, recorded

Login, command, key creation, setting change — all audited with trace ID, actor, risk tier, and before/after state. Buffer-backed, async, survives restarts.

§ 02

How it's built

Vyzorix is a clean-layered Go monolith — domain logic has zero infrastructure dependencies. Delete the storage layer and the domain tests still pass. Wire does dependency injection at build time, not reflection. The database is a detail, not the foundation.

  • domain/ Entities, value objects, repository interfaces, the risk evaluator, the permission engine. Pure Go, 0 infra imports
  • application/ Services that coordinate domain objects: ScheduleJob, AcquireLease, Reconcile, AuthenticateApiKey. The command authorizer lives here
  • infrastructure/ SQLite/Turso repositories, JWT, sessions, argon2id, FCM, HMAC signing, log redaction, tracing. Raw SQL, no ORM
  • api/ Gin handlers, middleware (auth, CSRF, CORS, rate limit, tracing, scoped RBAC), GraphQL schema + resolvers, Wire-generated DI. 468 Go files
“Delete the infrastructure layer entirely and the domain tests still pass.” — from the architecture documentation
